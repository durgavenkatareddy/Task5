# Titanic Survival Data Analysis

##  Contents

- Visualizations: Heatmaps, Pairplots, Histograms, Boxplots, and Scatterplots
- Correlation analysis
- Feature-wise observations
- Summary of key insights

## Visuals Used

1. **Correlation Heatmap** - Shows relationships between numeric features
2. **Pairplot (Survival vs Features)** - Visualizes feature interaction colored by survival
3. **Count Plot (Sex & Class vs Survival)** - Highlights gender and class survival trends
4. **Age Distribution Histogram** - Displays age spread among passengers
5. **Boxplot (Age vs Survival)** - Compares age distribution across survival outcomes
6. **Scatterplot (Fare vs Age)** - Colored by survival to observe income-related trends
